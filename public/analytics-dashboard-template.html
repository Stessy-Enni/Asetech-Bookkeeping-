Included React & TypeScript Modules

Modular components engineered for dense telemetry, crisp alignment, and responsive layouts.

KPI Metric Widgets

src/components/MetricCards.tsx

Four-column KPI strip with tabular numerals, favorable/unfavorable trend deltas, and automatic period-over-period timeframe comparison.

Chart Modules

src/components/FinancialCharts.tsx

Zero-dependency SVG cumulative cash flow trajectory with hover tooltips paired with proportional category dominance breakdowns.

Collapsible Navigation Shell

src/components/Sidebar.tsx

Sticky left rail toggling between 256px expanded and 72px icon-only widths with persisted state and a mobile slide-over drawer.

High-Density Data Table

src/components/TransactionTable.tsx

Sortable transaction ledger supporting inline inspection, anomaly outlier flags, bulk selection delete, and instant search filtering.

CSV & Report Generators

src/components/FinancialReportModal.tsx

Interactive CSV column mapper alongside print-optimized executive financial reports with dedicated light-mode print CSS rules.

Role-Scoped Admin Controls

src/components/OwnerLogoControl.tsx

Passcode-protected owner controls for custom logo uploads and developer dataset views while keeping client views streamlined.
